# 宠物医疗知识库 V2

"
    "本文件是根据原 `pet-medical-knowledge-base-draft.json` 中的 10 个来源入口，重新整理的医学知识点库。与旧文件不同，本版本的 `knowledge_points` 只保留犬猫医学内容，不再把数据治理、向量检索和版权规则当成医学知识点。

"
    "## 内容范围

"
    "当前包含 23 条中文医学知识点，覆盖犬猫呕吐、泌尿系统、皮肤过敏、猫呼吸道疾病、营养、疫苗、疼痛、牙科、液体治疗和糖尿病等主题。具体医学页面 URL 写入每条记录的 `source_urls`。

"
    "## 来源使用方式

"
    "Merck 的 Dog Owners / Cat Owners 和 WSAVA、AAHA 指南页面是医学内容来源；Merck Permissions 只用于版权审查；中国兽医协会在本版本只作为中国本地规范线索，未据其首页抽取医学事实。

"
    "## 重要边界

"
    "所有记录均为 `pending_vet_review`，没有生成 embedding，也没有清除商业使用权限。导入生产库前，应由执业兽医逐条检查医学准确性、适用物种、风险等级、地区适用性和回答边界。

"
    "## 下一步

"
    "1. 由兽医逐条审核并补充版本、审核人、审核日期。
2. 将高风险和 critical 条目单独配置回答策略。
3. 确定 embedding 模型后再生成向量。
4. 将每条知识点导入 PostgreSQL，并以物种、主题、审核状态和风险等级进行过滤检索。
